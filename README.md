# MovieFinder 🎬

MovieFinder is a movie discovery web application built with HTML, CSS, and vanilla JavaScript. It uses the TMDB API to search for movies, display movie information, view detailed movie information, and manage a personal watchlist.

## ✨ Features

* 🔎 Search for movies using the TMDB API
* 🎬 Display movie posters, ratings, release years, and genres
* 📖 View detailed movie information
* ⭐ View movie ratings and runtime
* 📝 Read movie overviews
* ➕ Add movies to a personal watchlist
* ❌ Remove movies from the watchlist
* 🔢 Dynamic watchlist counter
* 🚫 Prevent duplicate movies from being added
* ⏳ Loading states while fetching data
* ⚠️ Error handling for failed API requests
* 🔒 Close the movie details modal using the close button, backdrop, or Escape key
* 📱 Responsive user interface

## 🔌 API

Movie data is provided by [The Movie Database (TMDB)](https://www.themoviedb.org/).

Movie images are served using TMDB's image API.

## ⚙️ Running Locally

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/movie-finder.git
```

2. Open the project folder.

3. Add your TMDB API credentials according to the project's JavaScript configuration.

4. Open `index.html` in your browser, or use a local development server such as VS Code Live Server.

## 🔐 API Key Security

This project was built as a frontend learning project, so the TMDB API credential is used from the client side.

**Do not commit your personal API token to GitHub.**

For a production application, API credentials should be handled securely on a backend/server rather than exposed in frontend JavaScript.
